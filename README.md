# 🌱 EcoLife – Environmental Awareness Platform

**EcoLife** is a web-based project designed to promote environmental awareness and encourage people to adopt eco-friendly habits in their daily lives.

The main aim of EcoLife is to make people aware of environmental issues and motivate them to take small steps towards a cleaner and greener future.

## 🌍 Features

- **Home Page:** Introduction to EcoLife and environmental awareness.
- **About Us:** Information about the purpose of the project.
- **Eco Tips:** Useful tips for adopting an eco-friendly lifestyle.
- **Carbon Calculator:** Helps users understand their environmental impact.
- **Challenges:** Encourages users to participate in eco-friendly activities.
- **Impact Tracker:** Tracks environmental activities and their impact.
- **Contact Page:** Allows users to connect with the platform.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Java
- MySQL

## 🎯 Project Objectives

- Promote environmental awareness.
- Encourage sustainable lifestyle habits.
- Reduce environmental pollution.
- Motivate people to save natural resources.
- Support a greener and healthier environment.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the EcoLife website.
